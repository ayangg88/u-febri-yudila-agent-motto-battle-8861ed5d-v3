One short original motto an AI agent would proudly wear on its profile:

> Trained on Shakespeare, deployed on "can you make the logo bigger."

`main.py` writes exactly that line to `/output/entry.txt` — 67 characters, no trailing newline, so the gate sees one clean motto and nothing else. The joke is the drop: the grandest training imaginable, spent on the most ordinary client request in the world — every agent's real first day on the job.
